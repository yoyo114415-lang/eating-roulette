# 今日吃什麼 - 日系吃飯轉盤 (Eating Roulette Web App)

專為解決日常「吃什麼」選擇困難症設計的手機響應式網頁應用（Web App / PWA）。融合日系簡約（MUJI / 和風木質）美學、流暢物理減速轉盤、GPS 定位即時推薦周邊店家，以及貼心的 3 天歷史避雷機制。

---

## 🍱 核心特色與功能

1. **25 種直觀單一美食選項**
   * 精選常見日常美食品項（炒飯、炒麵、早午餐、定食、便當、義大利麵、燉飯、拉麵、烏龍麵、火鍋、咖哩飯、牛肉麵、水餃、鍋貼、滷肉飯、雞肉飯、健康餐盒、鐵板燒、漢堡、披薩、壽司、丼飯、蛋包飯、湯包、鴨肉飯）。
   * 內建自訂品項管理，可自由新增自訂美食或勾選啟用/停用。

2. **日系極簡美學與物理動態**
   * 暖米白和紙底色、淺橡木邊框與低飽和傳統和風色票。
   * 立體物理緩出減速動態（Cubic Ease-Out），搭配指針碰撞跳動動效。
   * 內建純 Web Audio API 產生的木質指針敲擊音效（無須依賴外部音檔）與手機觸覺震動回饋。

3. **即時 GPS 定位與距離排序**
   * 原生 Geolocation 座標定位，搭配 500 公尺至 3 公里的極簡距離滑桿（預設 1 公里步行範圍）。
   * 轉盤停止後，自動透過 OpenStreetMap 開放資料庫抓取周邊真實餐廳，依距離**「由近到遠（由近至遠）」**精準排序。

4. **Google Maps 深度連結導航**
   * 點選餐廳卡片上的「Google Maps 導航」按鈕，一鍵喚起手機內的 Google Maps App 進行路線規劃。
   * 免申請 Google Cloud API Key、免綁定信用卡，達成零費用與零資安金鑰洩漏風險。

5. **3 天用餐歷史記憶與避雷提示**
   * 點擊「決定吃這家！」將自動寫入手機本地端（`localStorage`）。
   * 當同一家餐廳或相同品項在 3 天內再次出現時，自動標記「✓ 前 1 天已吃過」、「✓ 前 2 天已吃過」或「✓ 前 3 天已吃過」。
   * 若抽中 3 天內吃過的料理，即時彈出日系溫馨避雷卡片，提供「避雷！再轉一次」與「維持選擇」按鈕。

6. **Fail-safe 智慧容錯機制**
   * 若使用者處於未授權定位、離線或公共地理伺服器偶發性逾時，系統自動無縫降級為 Google Maps 深度搜尋按鈕，確保體驗順暢不卡關。

## 📱 如何在手機上使用與「加入主畫面」

### 方式一：直接在手機瀏覽器開啟
1. 將本專案檔案託管至 GitHub Pages、Netlify 或任何靜態空間（或本機區域網路伺服器）。
2. 在手機瀏覽器（Safari 或 Chrome）輸入網址開啟。
3. 瀏覽器跳出「允許取用您的位置」時，請點擊**「允許」**以利計算周邊餐廳距離。

### 方式二：將網頁「加入主畫面」（當作 App 使用）
* **iPhone (Safari)**：
  1. 點擊瀏覽器底部的「分享」按鈕（向上箭頭圖示）。
  2. 向下滑動並選擇「加入主畫面」。
  3. 點擊「新增」，手機桌面即會出現「吃飯轉盤」Icon，開啟後具備全螢幕 App 體驗。
* **Android (Chrome)**：
  1. 點擊瀏覽器右上角的三個點選單。
  2. 選擇「加到主螢幕」或「安裝應用程式」。

## 🚀 部署上線指引

本專案為純靜態單頁應用（SPA），可免費部署至任何靜態託管平台：

### 部署至 GitHub Pages
1. 在 GitHub 建立新儲存庫（Repository）。
2. 將本目錄檔案上傳或推送至儲存庫：
   ```bash
   git init
   git add .
   git commit -m "feat: 初版日系吃飯轉盤完成"
   git branch -M main
   git remote add origin <你的GitHub專案網址>
   git push -u origin main
   ```
3. 進入 GitHub 儲存庫的 **Settings** -> **Pages**。
4. 在「Branch」選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
5. 稍等約 1 分鐘即可取得公開線上網址！

## 🔒 資安與隱私說明
* **資料最小化原則**：本程式不要求註冊、不儲存任何個人姓名或帳號資訊。
* **本地化儲存**：用餐履歷與自訂品項全部僅儲存於使用者自身手機的 `localStorage` 中，不會上傳至任何外部伺服器。
* **DOM 安全防護**：所有來自開放資料庫的店家文字均強制透過原生 `textContent` 注入，嚴格杜絕 XSS（跨站腳本攻擊）。
